# Brand Name Construction Framework

## Semantic Root Generation

Generate roots on the fly for each product — do NOT use a fixed word list. Common English roots produce names that are already taken as domains and brands.

**How to generate roots:**

1. **Product metaphors** — What does the product feel like? What physical process is it analogous to? (e.g., a resume tailor is like a glove fitting, a key cutting, a lens focusing)
2. **Foreign language mining** — Find short, phonetically appealing words in Latin, Greek, Japanese, Finnish, Swahili, etc. that relate to the product's core concept. Truncate or blend them.
3. **Cross-domain analogies** — Borrow from biology (morph, gene, helix), music (riff, chord, cadence), architecture (vault, span, truss), chemistry (bond, ion, flux), etc.
4. **Phoneme invention** — Combine consonant-vowel clusters that *sound* meaningful but aren't real words (e.g., "zel", "tova", "kira", "vex", "nuro")
5. **Abbreviation blends** — Compress phrases into syllables (e.g., "tailored profile" → "taipro" → "Taprio")

**Rules:**
- Avoid roots that are standalone English dictionary words (e.g., "fit", "path", "scope", "edge") — they produce names that are almost always taken
- Prefer roots of 3-5 letters that feel suggestive but not literal
- Generate at least 15 unique roots before applying construction patterns

## Name Construction Patterns

Combine one or two generated roots with a structural pattern. Apply multiple patterns per root to maximize candidates.

| Pattern | Technique | Example |
|---------|-----------|---------|
| Root + era/ara/ura | Latinate temporal suffix | "kapt" → Kaptera |
| Root + io/ia/is/um | Soft Latinate ending | "veld" → Veldia |
| Root + ly/ly variant | Adverb-style | "zeph" → Zephly |
| Truncation + suffix | Cut root, add new ending | "profile" → "pro" + "fia" → Profia |
| Vowel shift | Swap a vowel for freshness | "tune" → Tuno |
| Letter removal | Drop an interior letter | "caliber" → Calibr |
| Two-root blend | Merge halves of two roots | "tailo" + "rex" → Tailrex |
| Phoneme + suffix | Invented syllable + real suffix | "vor" + "ity" → Vority |

## Phonetic Rules

A strong name should:
- Be 2-4 syllables
- Have one obvious pronunciation
- Avoid tongue friction (no "pthr", "xqz", clusters)
- Avoid doubled letters that create spelling confusion
- Pass the "phone test" — someone hearing it can spell it

## Anti-Patterns to Avoid

- Exact dictionary words (hard to own)
- Two real words smashed together awkwardly (e.g., "SmartBuild")
- Obvious "AI" suffix spam (e.g., "ThingAI")
- Hype words (Quantum, Meta, Hyper, Ultra)
- Hyperliteral names (ResumeBuilderProAI)
- Trend-driven suffixes (Web3, crypto-adjacent)
- Names that sound like pharmaceutical drugs

## Quality Scoring Matrix

Score each candidate 1-5 on these dimensions (reject below 20/30):

| Dimension | Measuring |
|-----------|-----------|
| Distinctiveness | Is it ownable and unique? |
| Pronounceability | Easy to say on first try? |
| Memorability | Sticks after one exposure? |
| Expansion Flexibility | Can the company pivot without renaming? |
| Legal Safety | Low confusion risk with existing brands? |
| Visual Brandability | Looks good in a logo / wordmark? |

## Risk Filters

### Phonetic Similarity
Reject if the name:
- Sounds nearly identical to a known tech brand
- Differs by only one letter from a major SaaS product
- Has market overlap with a similarly-named company

### SEO Isolation
The name should ideally produce:
- Empty or unrelated SERP results
- No dominant company owning page 1
- Not a medical term, drug name, or biotech acronym
- Not a foreign-language profanity

### Trademark Distance
Without a formal USPTO search, screen by rejecting names that:
- Already exist in the software class
- Already exist in the product's industry vertical
- Are obvious derivatives of major brands

## Future-Proof Test

Ask these questions about each finalist:
1. If this becomes a $50M ARR company, does the name still feel credible?
2. If the product pivots to a broader market, does the name still fit?
3. Would you feel comfortable saying this name in an investor meeting?

If hesitation on any → discard.

## Psychological Check

- Bad sign: You like it because it's clever
- Good sign: It feels stable, slightly boring, clean
- Strong brands often feel neutral at first — they grow into meaning
